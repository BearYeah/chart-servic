## 口径不能隐藏

- “当前”依用户选定日期00:00、出生地固定UTC偏移计算。历史保存该日期，复算不偷偷更新成今天；不自动查询夏令时。
- 八字沿用上游默认起运法，后续交接按首运历时每十个公历年递推；闰日截到月末，左闭右开。比较前将基准日换算到所选八字历时坐标；公历年度标签不冒充精确交接日期。
- 八字关系仅检查本命四柱，不混入胎元与命身宫。三支齐备与两支关系分开，合不等于化；通禄暗合、天干冲、墓库等注明所用表。伤官不属于财官杀筛选。
- 季节旺衰采用月支四季法、辰戌丑未土旺，非精细交节旺衰。神煞沿用原项目年干支主位与月柱基组。藏干按原库顺序列，不强贴统一“本中余”标签。
- 紫微年界／四化／闰月使用页面选择。来因不取子丑。借星不复制为本宫实星，自化只按实星定位。大限流年重映射宫名与宫干飞化，不宣称已重安全部流曜。
- Arudha 使用古典七曜宫主，不使用节点副主；等数落原宫／对宫时，从落点取第十座。Arudha 宫号按整宫星座关系，与可选 D1 等宫显示区分。
- 卡拉卡8星制罗睺逆量、无计都；7星制无交点。同度冲突明确提示未定，不任意确认 AK／DK。
- 节点尊贵不指定；自然友敌不等于复合友敌。燃烧只用 D1 实际黄经，分盘度数不作真实距日角。
- 落陷取消只列落陷星座主／擢升星座主居上升或月亮角宫的候选条件，不宣布完整格局成立。其他未检查格局不能写“无”。
- 年度表含基准所在干支年；PD窗口则覆盖基准起3／5个公历年，并列出与窗口相交的完整运期。主运不足时延长计算，不凭空外推缺失运期。

## 暂不作程序结论

格局成败、喜忌取用、合化成功条件、开闭库／入墓效力、完整落陷取消与其他特殊格局、婚财健康等现实断语。
这些不自动填写成事实，后续 AI 也应区分“盘面字段”“传统解释”“待现实核对的假设”。程序结果不证明术数预测有效。

## 验证与操作边界

- 81项 Python 测试与10组 Node 回归通过，覆盖合成生辰、年界／换运边界、拓扑、飞化落点、卡拉卡、Arudha例外、运期连续性、模板历史保存、三次独立请求、原文提示词、状态恢复和跨阶段显式转交。
- 33个上游JS／JSON源文件哈希保持不变。测试通过不代表所有日期／流派均获独立权威校验。
- 浏览器实测：生成三份模板、复制、Markdown下载、页签键盘切换、390px手机与桌面布局。依据 web-design-guidelines 保留可读标签、状态播报、可见焦点和局部滚动区。
- 测试仅用合成生辰与模拟接口，无真实模型费用，不使用用户案例或真实API Key，未改动实际历史记录。原始参考模板文件未修改。
- 健康接口版本1.8、命盘数据版本2.0。旧版命盘快照可查看，生成新模板须重新排盘。先重启Python服务，再刷新网页。
